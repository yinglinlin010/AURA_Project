# AURA four-display reference

Open `index.html` locally with the `assets/` folder alongside it. No build, server or external requests are required.

Tabs select Center, Passenger, Rear and Window. Use the separate Simulation Console to change load, connectivity and presence. Passenger/rear proposals update the local journey only after Center approval.

This is an interactive design reference, not the production React simulator or gateway integration. See `../../AURA_Four_Display_Implementation_Target_2026-10-03.md` for implementation and acceptance requirements.

The six WebP assets are cropped from the repository's final reference images. Maps, places and measurements are fixtures. Media has no audio; calls and climate do not affect hardware.

JavaScript syntax and interaction handlers passed mock DOM checks. Browser screenshot comparison could not run in the creation environment.
