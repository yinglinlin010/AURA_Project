# AURA 可操作座艙

預設介面是五個同步顯示器：駕駛儀表、駕駛共享行程、前座媽媽、後座與智慧車窗。舊展示可從 `?legacy=1` 開啟；新座艙以後端共同狀態為準。

## 啟動

在專案根目錄執行 `npm run start:cabin`，預設 WebSocket 是 `127.0.0.1:8198/ws`。另一個終端執行：

```sh
VITE_AURA_WS_PORT=8198 npm run dev --prefix apps/web-simulator -- --host 127.0.0.1 --port 5198
```

開啟 http://127.0.0.1:5198/ 。在駕駛面板或前座媽媽的「行程」頁設定起點、終點，按「設定並計算共享路線」。正常座艙頁不顯示控制器；Demo 人數與網路模擬可從頁尾的獨立控制器入口 `?control=1` 操作。獨立顯示器連結同樣位於頁尾。

Gemini 金鑰由後端環境變數 `GEMINI_API_KEY` 提供，不傳給前端。不要把金鑰放在程式碼或提交到 Git。預設模型為 `gemini-3.5-flash-lite`，可透過 `GEMINI_JOURNEY_MODEL` 設定。先前提供的金鑰用於本次執行程序的記憶體，沒有寫入設定檔。

## 可操作流程

1. 智慧車窗每六秒輪播示範窗景，包含慢速移動與淡入切換。直接點擊窗景即截取同一張畫布的當下像素，媽媽收到 JPEG 截圖；確認後移除。相機與額外拍照按鈕已移除。此為 Demo 輪播，並非即時車外攝影機。
2. 前、後座有各自的語音輸入。允許麥克風後會顯示實際音量動畫，停頓或按結束後送出錄音，辨識字幕出現在相反座位。鍵盤字幕測試會標示為鍵盤來源。
3. 景點頁可語音搜尋、直接搜尋或請 AI 推薦；候選地點經 OSM 驗證。選擇候選即發起投票，通過後才重新計算與原行程整合的路線。
4. 全螢幕同步顯示投票。固定本次乘員名單，每人一票，必須嚴格過半且駕駛同意。駕駛否決、票數不足、逾時或名單改變會呈現結果。路線服務失敗時保留原行程，可重試。
5. 駕駛在出發前按「啟用駕駛免持確認」授予麥克風權限。新投票出現時自動收音，說「我同意加入行程」或「我不同意」。含糊或疑問語句不會算同意。每段錄音最多 20 秒，綁定當次投票，不能誤套到下一輪。
6. 照片的 AI 搜圖會分析景色，以 Wikimedia Commons 找到實際圖片後比較視覺相似程度，附來源與授權。這是相似圖片搜尋，不能據此宣稱拍攝位置已被確認。

## 地圖與本機 AI

地圖使用 OpenStreetMap 圖磚與可見著作權標示；地點透過 Nominatim，附近景點透過 Overpass，道路導航與順序最佳化透過 OSRM。沒有即時路況。最多八個中途景點。Nominatim 使用快取、排隊且每次查詢間隔至少 1.1 秒，不做自動完成；遵守 [使用政策](https://operations.osmfoundation.org/policies/nominatim/)。公共服務可能忙碌，介面會顯示錯誤，不能視為有服務保證的商用部署。

可用 `AURA_OSM_SEARCH_URL`、`AURA_OSM_POI_URL`、`AURA_OSRM_URL` 與前端 `VITE_AURA_OSM_TILE_URL` 切換自建服務。不使用 Mapbox token，不在離線時預抓公共圖磚。

本機語音使用 ffmpeg 與 whisper-cli，預設讀取 `~/.cache/whisper/ggml-base.bin`，也可設 `AURA_WHISPER_MODEL`、`AURA_WHISPER_CLI`、`AURA_FFMPEG_CLI`。本機旅程建議使用 Ollama 的 `qwen3:8b`（可設 `AURA_LOCAL_MODEL`），只連 loopback。本機模式可以辨識語音與產生建議；新地點驗證、路線計算及圖片搜尋仍需要連線，離線時不會假裝成功。

## 保存與 Android

`start:cabin` 把已核准行程和乘員人數原子寫入 `data/aura-cabin-state.json`；重啟時還原。可設 `AURA_CABIN_STATE_FILE`。不保存照片、錄音、字幕、投票或 API 金鑰。正在投票的景點不會因重啟而加入。

Android debug WebView 已改成針對可信任的 localhost 頁面請求系統麥克風／相機權限，支援選取照片並在背景暫停收音。已完成 debug APK 建置；實體車機尚未驗收。連本機開發伺服器時可使用 `adb reverse tcp:5173 tcp:5198` 與 `adb reverse tcp:8198 tcp:8198`。

## 驗證範圍

後端測試包含照片權限、跨座位字幕、名單改變、逾時、駕駛否決、失敗重試、過期錄音、非同步路線競態與保存的資料最小化。`scripts/check-cabin-ui.mjs` 是隔離服務的瀏覽器驗證。

另已實際呼叫 Gemini、Nominatim、Overpass、OSRM、Wikimedia 圖片與本機 Whisper；瀏覽器錄音測試使用合成輸入，不能取代實體麥克風、相機及多台車機驗收。控制器人數是攝影機感知的模擬輸入，尚未接入真正的人員偵測模型。停止汽車動畫按鈕與駕駛負荷控制列已移除。

本次完整檢查：228 項 Node 測試、14 項 Python 檢查、協定雜湊驗證與 Web 建置通過。Web bundle 仍有大小警告。Android debug APK 建置通過。

刪除功能位於車內面板，控制器沒有刪除入口。前座媽媽的「行程」頁可按鍵或語音刪除；駕駛面板提供「語音刪除行程」，可說「刪除鯉魚潭」、「移除景點鯉魚潭」或「清空行程」。疑問、否定、模糊名稱或已過期的行程錄音不會執行。刪除景點時先取得新路線，成功後才同步更新 Core 與保存檔；失敗則保留原行程。駕駛畫面保留路線與簡短投票、語音確認，移除景點搜尋及對話頁。

選擇景點前，提議者可在候選清單設定是否投票、幾秒後開始（0～3600 秒）與持續時間（10～300 秒）。0 秒代表立即開始。開啟投票時維持過半且駕駛同意；不投票時只需駕駛確認，其他乘員不會出現投票按鈕。延後投票從正式開始後才計算期限，名單或行程變更會取消排定的投票。

修改起點與終點會保留已核准的中途景點並重新最佳化路線。語音確認綁定原投票，投票結束後不能轉而確認另一個提案。協定驗證失敗會回傳對應請求的錯誤，介面不會一直等待。

## 開始導航

駕駛行程面板可按「開始導航」，允許瀏覽器定位後使用 GPS。介面只保留 GPS「開始導航」，已移除 Demo 導航按鈕。導航會同步車輛位置、下一個轉向、剩餘距離與估計時間；轉向資料由 OSRM 提供，非即時交通。地圖會跟隨車輛位置，儀表板同步速度。可按「結束導航」，抵達後顯示結果；路線修改會停止舊導航，須重新開始。GPS 精度不足、過期或偏離路線會明確提示，不會假裝已抵達。偏離後目前需由面板重新規劃路線，尚無自動偏航重算。導航位置不寫入行程保存檔。

Android debug 容器已加入 localhost 頁面的系統定位權限請求。已完成 APK 建置；瀏覽器 GPS 驗證使用模擬位置，實體裝置 GPS 尚待現場驗收。

投票通過、未通過、取消與逾時的通知在結果確定後顯示5秒，所有面板同步收起。重新連線不會再次顯示已過期的通知；後端結果與行程仍保留。

## 已查詢景點的離線快取

查詢結果與關鍵字索引寫入 `data/aura-place-cache.json`，重啟後載入。保留最近500個景點與200組查詢索引，可用 `AURA_PLACE_CACHE_FILE` 設定位置。景點頁按「查詢已儲存景點」可完全使用本機資料；留空可看最近5筆，輸入名稱可篩選。一般搜尋在離線模式或外部搜尋失敗時，也會嘗試已有資料。

結果標示已儲存、原查詢時間與非即時來源。不保存照片、錄音、API金鑰或GPS位置。新地點查證與路線重算仍需外網。舊版沒有寫入磁碟的歷史查詢不能全部補回，需重新查詢；保存行程中的地點會作為初始快取。

## 最後版本：本地 AI 可靠性改善

離線推薦直接使用磁碟快取中的候選景點，即使未設定起點也能推薦；未設定起點時會明確說明無法確認附近或順路。先依需求、類別與已知位置選出最多12個候選，再交給本機模型排序，模型只能回傳候選索引，不能自行新增地名。重複名稱會合併；成功建議的說明由已知資料生成，避免虛構設施。

預設使用已安裝的 qwen3:8b，保留模型10分鐘並採結構化輸出。Ollama 無法使用時提供明確標示的「本機資料篩選備援」。要求保證免費、營業時間、座位或步行距離等資料，而快取無法證明時，會說明資料不足，不會當作已驗證。

語音辨識加入行程地名提示、繁體轉換；語音刪除只在完整地名同音、同聲調且唯一匹配時校正，例如「禮魚潭」對應已存在的「鯉魚潭」。不會以模糊辨識改寫同意或否決。

驗證中，原本三種離線查詢皆出現 OFFLINE_PLACE_UNAVAILABLE，修正後三種皆取得快取候選。四個共同的簡單推薦題，本機與 Gemini 都選中預期第一候選；這是小型測試，不能推論本機模型全面達到雲端能力。另有資料不足保護與本機服務故障備援測試。合成語音已確認同音地名修正；實體收音、噪音與不同口音仍需現場測試。

## 四面板全螢幕投票，儀表保持顯示

正式投票開始時，駕駛行程、媽媽、後座及智慧車窗四個面板切換為同意／不同意選項；駕駛儀表不顯示投票與結果，持續顯示原本資訊。獨立面板入口覆蓋整個瀏覽器畫面；全部畫面入口覆蓋每一個面板。投票後保留該畫面，顯示自己的選擇並等待結果；同一乘員在多個面板同步投票狀態，不重複計票。後座多名乘員仍可切換身份。駕駛行程面板保留語音投票與免持確認。

通過、未通過、取消、逾時結果以全螢幕顯示五秒，之後恢復原本頁籤與內容。排定投票在尚未開始時維持原面板；路線最佳化期間繼續顯示等待畫面。路線計算錯誤保留重試，不當作已完成結果自動消失。

投票介面已簡化：主要畫面只保留「要加入行程嗎？」、景點名稱與「同意／不同意」。移除逐人票況、票數與重複規則說明；選完顯示「等待結果」與自己的選擇。駕駛仍可語音投票，多名後座乘員仍可切換身份。判定規則及結果五秒自動收起維持原行為。

景點選項頁預設只顯示候選景點及「發起投票」操作；加入方式與開始／持續時間收在「調整設定」中。預設立即開始60秒投票，展開後仍可設定不投票、延後開始或更改期限。

投票結果確定後，未通過仍保留原路線與投票前頁籤；通過會立即加入景點並更新共享路線，結果五秒後，駕駛／媽媽回到行程，後座回對話、車窗回景色。已有 GPS 導航會切換至新行程版本繼續接收定位，無須重按開始；未開始導航不會自動要求定位。手動改起終點、刪除景點仍沿用停止旧導航的行為。

## 語音與判斷第二次加強

預設語音優先使用本地 Whisper small（`data/models/ggml-small.bin`，已核對官方權重 SHA-256），沒有 small 時仍可用既有 base。可用 `AURA_WHISPER_MODEL` 指定模型，`AURA_SPEECH_PROVIDER=cloud` 優先雲端；本地出錯且連網時可用雲端備援。各用途提供不同詞彙與已知地名提示，不將對話錄音套用投票指令提示。瀏覽器加入自動增益、單聲道及較高錄音位元率，說話停頓等待延長至投票1.7秒、其他用途2.3秒；沒有偵測到聲音不送辨識。

針對使用者確認的「鯉魚潭」被辨識成「李魚殘」，新增只在已知景點含鯉魚潭時套用的校正。支援「好的，我同意」「先不要」「把鯉魚潭刪掉」等口語；疑問、否定、條件語句與多義地名仍不執行。原始聲音與錄音不持久保存。

推薦加入咖啡、餐飲、公園等排除條件，特定類別沒有候選時不以無關地點充數。雲端與本機皆失敗、格式錯誤或回傳名單外索引時，提供明確標示的資料篩選備援。

四句合成中文語音中，small 的鯉魚潭地名與同意／不同意皆正確；base 在刪除句辨識成李瑜潭。這不代表已驗證使用者本人、車內噪音或所有口音，需要以現場錄音驗收。
